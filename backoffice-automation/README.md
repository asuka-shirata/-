# バックオフィス業務自動化デモアプリ

勤怠CSVから総支給額を計算し、銀行明細CSVから仕訳データを作るデモアプリです。
起動のときに一度だけコマンドを使いますが、その後の操作はすべてブラウザ上で行えます。

| 機能 | 入力 | 出力 |
|---|---|---|
| 💰 給与計算の自動化 | 勤怠CSV | 給与システム取り込み用CSV（`payroll-import.csv`） |
| 📒 経理仕訳の自動推論 | 銀行明細CSV | 会計ソフト取り込み用CSV（`journal-import.csv`） |

## 起動手順

### 1. ターミナルを開く

- **Mac**：`command` + `スペース` を押し、「ターミナル」と入力して `return`
- **Windows**：スタートメニューで「PowerShell」と検索して開く

### 2. このフォルダに移動する

`cd`（最後に半角スペースを入れます）と入力し、ターミナルの画面に `backoffice-automation` フォルダをドラッグ&ドロップして、`Enter` を押します。

### 3. 必要なライブラリをインストールする（初回のみ）

```bash
pip install streamlit pandas
```

### 4. アプリを起動する

```bash
streamlit run app.py
```

ブラウザが自動で開き、アプリが表示されます。初回にメールアドレスを聞かれたら、**何も入力せず `Enter`** を押してください。

### 5. アプリを終了する

ターミナルで `control` + `C`（Windowsは `Ctrl` + `C`）を押します。

## 使い方

1. 左のサイドバーで機能を選びます。
2. CSVをアップロードします。手元にCSVがなければ「サンプルデータで試す」にチェックを入れます。
3. 画面の結果を確認し、「CSVをダウンロード」を押します。

サンプルデータは、このフォルダの `sample-payroll.csv` と `sample-bank.csv` です。

## 計算と推論のルール

### 給与計算

```text
時間単価 ＝ 基本給 ÷ 所定労働時間
残業代   ＝ 時間単価 ×（60時間までの残業 × 1.25 ＋ 60時間超の残業 × 1.5）
欠勤控除 ＝ 時間単価 × 所定労働時間に足りない時間
総支給額 ＝ 基本給 ＋ 通勤手当 ＋ 残業代 − 欠勤控除
```

- 残業代・欠勤控除は、1人ごとに1円未満を四捨五入します。
- 割増率は画面で変更できます。
- 「実労働時間」は残業時間を含む時間として扱います。

### 仕訳の推論

- 摘要にキーワードが含まれているかを、ルール表の上から順に調べます。
- 入金は「借方：普通預金／貸方：推論した科目」、出金は「借方：推論した科目／貸方：普通預金」にします。
- どのルールにも当てはまらない取引は、仮の科目（入金は仮受金、出金は仮払金）にして「要確認」と表示します。
- ルール表は画面で編集できます。ただし、編集内容はブラウザを再読み込みすると元に戻ります。ずっと使うルールは、`app.py` の `DEFAULT_RULES` に書き足してください。

## 実務で使う前に確認すること

このアプリはデモのため、次の内容は扱っていません。

- 所得税・住民税・社会保険料の控除、深夜・休日の割増
- 基本給以外の手当（役職手当など）を含めた時間単価の計算
- 消費税の区分
- API連携（CSVでのやり取りのみ）

出力するCSVの列は汎用的な形式です。お使いの給与システム・会計ソフトの取り込み形式に合わせて、`app.py` の `export_columns` を調整してください。計算結果と仕訳は、必ず担当者が確認してください。

## 困ったときは

| 症状 | 対処法 |
|---|---|
| `pip: command not found` | `python3 -m pip install streamlit pandas` を試す |
| `externally-managed-environment` と表示される | 下の「仮想環境を使う方法」を試す |
| `streamlit: command not found` | `python3 -m streamlit run app.py` を試す |
| CSVの列が見つからないと表示される | CSVの1行目の列名を、サンプルCSVと同じ名前にする |
| 時間が数字ではないと表示される | `12:30` のような形式を `12.5` に直す |

### 仮想環境を使う方法（Mac）

次のコマンドを順番に実行します。

```bash
python3 -m venv venv
```

```bash
source venv/bin/activate
```

```bash
pip install streamlit pandas
```

```bash
streamlit run app.py
```
