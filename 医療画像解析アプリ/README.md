# 医療画像解析アプリ（デモ / プロトタイプ）

CT・MRI画像のような医療画像データを読み込み、付帯情報（タグ）の修正・画像解析・匿名化・PDFレポート出力を行う、社内利用向けStreamlitアプリのデモです。実データが無くても、ダミーの画像・メタデータを自動生成して一通りの機能を試せます。

## ⚠️ 注意事項

- 本アプリはデモ / プロトタイプです。表示される画像・付帯情報はすべて自動生成されたダミーデータで、実在の患者データではありません。
- 解析結果（大きさ計測・濃度解析）は、輝度しきい値による簡易計算のプレースホルダーです。臨床判断には使用できません。
- 実運用では `modules/analysis.py` の関数を、OpenCVや医療画像用ライブラリ（pydicom / SimpleITK 等）を用いた本格的な実装に差し替えてください。

## セットアップ

```bash
cd 医療画像解析アプリ
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## 起動方法

```bash
streamlit run app.py
```

ブラウザで `http://localhost:8501` が開きます。社内サーバーで起動する場合も、追加のインフラ構築は不要です。

## 使い方

### ① データ一覧（サイドバー + タブ1）
サイドバーで生成件数（10〜20件、任意で乱数シード）を指定し「ダミーデータを生成」を押すと、患者情報とスライス画像群を持つ検査データが自動生成されます。タブ1で一覧を確認できます。

### ② 画像表示・タグ編集
サイドバーで対象検査を選択し、スライダーでスライス画像を切り替えながら表示できます。右側のフォームで患者氏名・ID・生年月日・性別・モダリティ・部位・撮影日・備考を修正し「保存」できます。

### ③ 画像解析
対象スライスと計測しきい値を指定すると、対象物の面積・推定径（大きさの計測）と、輝度の平均・標準偏差・最小/最大値およびヒストグラム（濃度解析）が表示されます。いずれもプレースホルダー実装です。

### ④ 匿名化
サイドバーの「個人情報を匿名化して表示」トグルをONにすると、アプリ全体で患者氏名・患者ID・生年月日、および画像左上の焼き付け文字がマスキングされます。タブ4では匿名化前後を並べて比較できます。

### ⑤ レポート出力
代表スライスを選択し「PDFレポートを生成」を押すと、検査情報・代表画像・解析結果をまとめたA4 1枚程度のPDFが生成され、ダウンロードできます。「匿名化した状態でレポートを出力する」はデフォルトON（推奨）です。

## ファイル構成

```
医療画像解析アプリ/
├── app.py                    # メインのStreamlitアプリ
├── modules/
│   ├── data_generator.py     # ダミー画像・付帯情報の生成
│   ├── analysis.py           # 画像解析（大きさ計測・濃度解析）のプレースホルダー
│   ├── anonymizer.py         # タグ・画像の匿名化処理
│   └── report.py             # PDFレポート生成
├── requirements.txt
└── README.md
```

## 今後の拡張ポイント

- `modules/analysis.py`: しきい値処理をOpenCV/scikit-imageによるセグメンテーションに置き換え、CT値（HU）変換など実データに即した計算を追加する。
- `modules/data_generator.py`: 実際のDICOMファイル読み込み（pydicom）に置き換える。
- `modules/anonymizer.py`: DICOMタグの匿名化ルールを施設のポリシーに合わせて拡張する。
